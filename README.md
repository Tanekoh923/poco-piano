# poco — 音を、あそぼう。

スマホの縦画面で遊べるピアノリズムゲームです。白鍵「ドレミファソラシド」8つと黒鍵5つに対応しています。依存パッケージは不要です。

## スマホで遊ぶ

[poco を開く](https://tanekoh923.github.io/poco-piano/)

スマホの Safari や Chrome で開き、「演奏をはじめる」をタップしてください。

## 起動

Node.js を入れた PC で、このフォルダから `npm start` を実行し、`http://localhost:5173` を開きます。

スマホは PC と同じ Wi-Fi に接続して、`http://PCのLAN内IPアドレス:5173` をブラウザで開いてください。Windows のファイアウォールで通信の許可が必要になる場合があります。PC の IP アドレスは `ipconfig` の IPv4 アドレスで確認できます。

サーバーを使わず `index.html` を直接開くこともできます。スマホへの配布には、4つのファイル `index.html`、`style.css`、`songbook.js`、`game.js` を静的ホスティングに置けます。

## 遊び方

- 曲と難易度を選んで「演奏をはじめる」を押します。
- 音符の下端がラインに重なるタイミングで、同じ音の鍵盤をタップします。緑色は白鍵、橙色は黒鍵です。
- PC の白鍵は A / S / D / F / G / H / J / K、黒鍵は W / E / T / Y / U キーです。Esc で一時停止・再開します。
- 複数の指で同時に押したり、指を滑らせて別の鍵盤を弾いたりできます。
- 正確なタップで Perfect、少しずれると Good、通り過ぎると Miss になります。空打ちはコンボが途切れます。
- 全音符の判定から正確さを計算し、Perfect を100%、Good を75%、Miss を0%として集計します。
- 演奏後にランク、スコア、最大コンボが表示されます。ベストスコアは曲・難易度別にブラウザに保存されます。
- 画面を切り替えると自動的に一時停止し、再開時は短いカウントダウンが入ります。
- 待機画面でも鍵盤を押すと自由に音を鳴らせます。

昔からの旋律を1オクターブで遊べる単旋律にしています。歌詞や外部の演奏音源は収録していません。休符では音符を流さず、その分の時間を空けます。長い音は最初のタップだけを判定します。音符は実際の鍵盤の位置へ流れ、押した鍵盤の音が鳴ります。音は Web Audio で合成したピアノ風の音色です。

旋律・リズム確認の参考資料：[かえるの合唱](https://kodomomusiq.com/score05-kaeru/)、[むすんでひらいて](https://kodomomusiq.com/score04-musunde/)、[かたつむり](https://doreminotes.jp/katatsumuri/)、[1869年のフレール・ジャック](https://fr.wikisource.org/wiki/Chansons_et_rondes_enfantines/Fr%C3%A8re_Jacques)。楽譜画像や伴奏の編曲は転載していません。

13鍵版のベストスコアは、以前の4鍵版とは別に保存します。

## 構成

- `index.html`: 日本語の画面
- `style.css`: PC・スマホのレイアウト
- `game.js`: 音符、判定、音声、スコア、一時停止
- `songbook.js`: 13曲の旋律、テンポ、休符を含む音符データの読み取り
- `server.cjs`: LAN からも接続できる開発用サーバー

実機での音声遅延は端末や Bluetooth イヤホンによって変わります。最初は本体のスピーカーや有線イヤホンでお試しください。

`npm test` で13曲×3難易度の演奏・スコア保存と、休符、音程、入力、一時停止を確認できます。`npm run check` で構文を確認します。
